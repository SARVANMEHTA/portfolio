Green Cloud Optimization

Problem

Design a tool that lets DevOps teams monitor, analyse and reduce the energy use and carbon emissions of their CI/CD pipelines.

Solution

A real-time dashboard that tracks CPU and memory, converts usage into energy and carbon per build, and suggests optimisations.

Key features

  • Dashboard with total energy, carbon footprint, cost and a green score
  • Resource utilisation and build duration trends
  • Idle alert when CPU drops below 10%
  • Rule engine and Gemini AI project insights
  • Energy calculator, prediction and reports pages

Machine learning

A linear regression model predicts an energy risk score (0 to 100) and forecasts CO₂ emissions.

My contribution

  • CI/CD integration: built the layer that collects pipeline execution data (build duration, number of jobs, pipeline status, stage information) from DevOps platforms through webhook and API communication.
  • Energy and carbon calculation: built the module that turns CPU use, execution time and resource usage into energy per pipeline, then into estimated CO₂ per build using carbon-intensity data, and tracks CO₂ trends and savings.

Flow: pipeline, resource usage, energy estimate, carbon intensity, CO₂ emission.

Team and recognition

Built at a hackathon by a team of 5. Presented as a paper by a team of two, which won 2nd prize at the 16th National Level Technical Symposium, held at Ashoka Women's Engineering College on 25 March 2026.

Tech stack

JavaScript, Python, Gemini AI.

CampusGuard AI

Problem

Campus gates have no automatic way to notice a suspended student entering, and a wrong automatic alert would harm an innocent visitor.

Solution

A pipeline that captures gate video, detects faces with YuNet, turns them into 128-dimension SFace embeddings and matches them against suspended students using cosine similarity. Matches go into confidence-tiered review queues, and an admin must verify each one before an email alert is sent.

Key features

  • Live gate console in the browser, plus a command-line daemon for webcams, RTSP cameras and video files
  • High and low confidence review queues with one-click verify or reject
  • REST API for students, detections, queues and statistics
  • Audit log of detections and duplicate-alert cooldowns
  • 9 automated unit and integration tests

Tech stack

Python, Django, OpenCV, YuNet, SFace, SQLite. Deployed on Render.

My role

Lead developer: I built most of the system end to end. College assignment, team of 2.

Live demoGitHub

SIGNAL: AI Reel Interest Agent

Problem

Recommenders that match keywords fall into two traps. The keyword trap suggests another Java clip to someone who is really interested in a software engineering career. The hype trap pushes clickbait such as "10 AI tools to make $10k/month" to anyone curious about AI.

Solution

An agent that reasons over the full ordered watch history, infers the underlying interest, and recommends grounded educational tech content from a curated pool.

Key features

  • Side-by-side comparison of a naive matcher and the SIGNAL agent for every step
  • Interest distribution across 8 categories, normalised to 1.00
  • Anti-hype shield with an audit log of every rejected clickbait candidate
  • Works offline with a calibrated engine, with optional Claude API inference
  • Five regression tests (trap, narrow interest, hype, cold start, all-hype), all passing

My role and event

Solo project. Built for PromptWars X RGMCET, conducted by the CSE Department at RGMCET. Thanks to Hack2Skills.

Tech stack

JavaScript, HTML, CSS, Node.js test runner, optional Anthropic Claude API.
